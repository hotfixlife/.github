# Hotfix Life

Don't settle for the broken things life gives you. Fix them! This is the code behind the fixes.

Each repo here comes from an episode of [Hotfix Life on YouTube](https://youtube.com/@hotfixlife), with a write-up on [Substack](https://hotfixlife.substack.com): built at home with AI, shared so you can use it or build your own.

Projects are shared as-is. Expect rough edges, and feel free to open an issue.

If something here helped you, you can [buy me a coffee](https://buymeacoffee.com/hotfixlife).
